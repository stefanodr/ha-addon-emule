## HaMedia v0.1.3

### Changed
- The icon TVs and players show for the HaMedia server is now the same television with a play button as the add-on. MiniDLNA is rebuilt at image build time with its four built-in icons replaced.

### Note
- The first build/update takes a few minutes longer (MiniDLNA is compiled).
- Some TVs cache the old icon: restart the TV or reopen the media server list if it does not change.

## HaMedia v0.1.3

### Modifiche
- L'icona che TV e lettori mostrano per il server HaMedia è ora la stessa televisione con tasto play dell'add-on. MiniDLNA viene ricompilato durante la creazione dell'immagine sostituendo le sue quattro icone interne.

### Nota
- La prima installazione/aggiornamento richiede qualche minuto in più (compilazione di MiniDLNA).
- Alcune TV conservano l'icona vecchia in cache: riavvia la TV o riapri l'elenco dei server se non cambia.
