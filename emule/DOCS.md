# eMule

## English

This add-on runs eMule Community under Wine. Open **eMule** from the sidebar to use the full interface.

1. Start the add-on and open the sidebar entry.
2. Forward TCP 4662 and UDP 4672 on your router to this machine to get a High ID.
3. Downloads are saved in `/media/emule/Incoming` by default (option `download_path`).

If eMule does not start, enable `install_vcredist`, restart the add-on and check the log. Supported on amd64 only.

Full documentation: <https://github.com/stefanodr/ha-addon-emule>

## Italiano

Questo add-on esegue eMule Community con Wine. Apri **eMule** dalla barra laterale per usare l'interfaccia completa.

1. Avvia l'add-on e apri la voce nella barra laterale.
2. Inoltra TCP 4662 e UDP 4672 dal router verso questa macchina per ottenere un ID alto.
3. I download vengono salvati in `/media/emule/Incoming` per impostazione predefinita (opzione `download_path`).

Se eMule non si avvia, attiva `install_vcredist`, riavvia l'add-on e controlla il log. Supportato solo su amd64.

Documentazione completa: <https://github.com/stefanodr/ha-addon-emule>
