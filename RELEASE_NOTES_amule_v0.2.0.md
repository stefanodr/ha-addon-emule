## aMule add-on v0.2.0 — first stable release

The add-on is now marked **stable**, after tests on a mini PC running Home Assistant OS with downloads on a USB SSD.

### Measured against the eMule add-on (same machine)
| | eMule (Wine) | aMule |
|---|---|---|
| CPU at rest | 5.7-6.3% | 0.4% |
| RAM at rest | 2.0-2.1% | 0.5% |
| CPU downloading a film | 26.8% | 1.9% |
| RAM downloading a film | 5.7% | 3% |

### What's new
- New README in English and Italian with the comparison and when to choose each add-on.

### Note
- No change to the add-on behavior compared with 0.1.0. Both add-ons use ports 4662/4672: run only one at a time.

## Add-on aMule v0.2.0 — prima versione stabile

L'add-on è ora **stabile**, dopo le prove su un mini PC con Home Assistant OS e download su un SSD USB.

### Misure rispetto all'add-on eMule (stessa macchina)
| | eMule (Wine) | aMule |
|---|---|---|
| CPU a riposo | 5.7-6.3% | 0.4% |
| RAM a riposo | 2.0-2.1% | 0.5% |
| CPU durante il download di un film | 26.8% | 1.9% |
| RAM durante il download di un film | 5.7% | 3% |

### Novità
- Nuovo README in inglese e italiano con il confronto e quando scegliere l'uno o l'altro add-on.

### Nota
- Nessuna modifica al comportamento rispetto alla 0.1.0. Entrambi gli add-on usano le porte 4662/4672: eseguine uno solo alla volta.
