# Changelog

## 0.2.0

**English**

- First **stable** release (no longer marked as experimental), after tests on a mini PC with downloads on a USB SSD.
- Measured against the eMule add-on on the same machine: idle CPU 0.4% (eMule 5.7-6.3%), idle RAM 0.5% (eMule 2.0-2.1%); while downloading a film CPU 1.9% (eMule 26.8%), RAM 3% (eMule 5.7%).
- New README in English and Italian with the comparison and when to choose each add-on.
- No change to the add-on behavior.

**Italiano**

- Prima release **stabile** (non più sperimentale), dopo le prove su un mini PC con i download su un SSD USB.
- Misure rispetto all'add-on eMule sulla stessa macchina: CPU a riposo 0.4% (eMule 5.7-6.3%), RAM a riposo 0.5% (eMule 2.0-2.1%); durante il download di un film CPU 1.9% (eMule 26.8%), RAM 3% (eMule 5.7%).
- Nuovo README in inglese e italiano con il confronto e quando scegliere l'uno o l'altro add-on.
- Nessuna modifica al comportamento dell'add-on.

## 0.1.0

**English**

- First experimental release: aMule 2.3.3 daemon with its web interface in the Home Assistant sidebar, no Wine and no virtual screen.
- Same ports as the eMule add-on (4662/TCP, 4672/UDP): run only one of the two at a time.
- Options: `download_path`, `require_external_disk`, `nickname`, `web_password` (random password generated if empty).

**Italiano**

- Prima release sperimentale: demone aMule 2.3.3 con la sua interfaccia web nel menu laterale di Home Assistant, senza Wine né schermo virtuale.
- Stesse porte dell'add-on eMule (4662/TCP, 4672/UDP): esegui un solo add-on alla volta.
- Opzioni: `download_path`, `require_external_disk`, `nickname`, `web_password` (password casuale generata se vuota).
