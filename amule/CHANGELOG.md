# Changelog

## 0.1.0

**English**

- First experimental release: aMule 2.3.3 daemon with its web interface in the Home Assistant sidebar, no Wine and no virtual screen.
- Same ports as the eMule add-on (4662/TCP, 4672/UDP): run only one of the two at a time.
- Options: `download_path`, `require_external_disk`, `nickname`, `web_password` (random password generated if empty).

**Italiano**

- Prima release sperimentale: demone aMule 2.3.3 con la sua interfaccia web nel menu laterale di Home Assistant, senza Wine né schermo virtuale.
- Stesse porte dell'add-on eMule (4662/TCP, 4672/UDP): esegui un solo add-on alla volta.
- Opzioni: `download_path`, `require_external_disk`, `nickname`, `web_password` (password casuale generata se vuota).
